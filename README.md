# 🍋 Blox Fruits Gacha & Trade Cooldown Tracker

A lightweight, cyberpunk-styled web utility designed to track Roblox Blox Fruits gacha and trade timers effortlessly. No more guessing or missing your rolls!

## ✨ Features
- **Accurate Countdowns:** Keeps track of both your standard 4-hour gacha cooldown and trade limits simultaneously.
- **Test Mode:** Includes fast 5-second debug modes to test alerts instantly.
- **Browser Notifications:** Sends desktop alerts when your timers hit zero, even if the tab is in the background.
- **Sleek Dark UI:** Minimalist and modern dark theme optimized for gamers.

## 🚀 Live Demo

## 🛠️ Usage
1. Open the website.
2. Click **"Başlat"** on the respective card to start your countdown.
3. Use the **"Test"** buttons if you want to test the notification system quickly.
