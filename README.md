# 🍋 Blox Fruits Gacha Cooldown Tracker

A lightweight, cyberpunk-styled web utility designed to track Roblox Blox Fruits gacha timers effortlessly. No more guessing or missing your rolls!

## ✨ Features
- **Accurate Countdown:** Keeps track of your standard 4-hour gacha cooldown.
- **Test Mode:** Includes a fast 5-second debug mode to test alerts instantly.
- **Browser Notifications:** Sends a desktop alert when your cooldown hits zero, even if the tab is in the background.
- **Sleek Dark UI:** Minimalist and modern dark theme optimized for gamers.

## 🚀 Live Demo
You can access the live version here:
👉 [https://ardakk-gamer.github.io/bloxfruits](https://ardakk-gamer.github.io/bloxfruits)

## 🛠️ Usage
1. Open the website.
2. Click **"Başlat (4 Saat)"** to start your standard 4-hour countdown.
3. Use **"Test Modu (5 Saniye)"** if you want to test the notification system quickly.
